# 📖 Overview

Anshul AutoPilot is a modern, AI-ready productivity web application designed to help students, developers, and creators manage their entire daily workflow from a single dashboard.

Instead of using multiple websites and applications for planning, studying, coding, note-taking, project management, and tracking progress, Anshul AutoPilot combines everything into one intelligent workspace.

The project follows a modular architecture, allowing new sections and features to be added without rebuilding the entire application.

Version 1.0 is intentionally built without external AI APIs. The application is designed so that Anti Gravity AI can be integrated in future versions without changing the core architecture.

# ⚙️ Installation Guide

## Prerequisites

Before running the project, make sure the following software is installed.

- Node.js
- npm
- Git
- VS Code (Recommended)

---

## Installation

Clone the repository

```bash
git clone https://github.com/yourusername/anshul-autopilot.git
```

Move inside project

```bash
cd anshul-autopilot
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

# 📌 Development Principles

The project follows several important principles.

## Modular Architecture

Every feature must be an independent module.

Examples

- Dashboard
- Planner
- Study Hub
- Coding Workspace
- Projects
- Skill Arena
- Analytics

Modules should never directly depend on each other.

---

## Reusable Components

Components should be reused whenever possible.

Examples

- Button
- Card
- Sidebar
- Modal
- Progress Bar
- Timer
- Charts

---

## Clean Folder Structure

Every module should have

- Components
- Styles
- Hooks
- Services
- Assets

inside its own folder whenever applicable.

---

## Responsive First

The application must support

- Desktop
- Laptop
- Tablet
- Mobile

---

## Performance

The application should

- Load quickly
- Avoid unnecessary rendering
- Use lazy loading
- Keep bundle size small
